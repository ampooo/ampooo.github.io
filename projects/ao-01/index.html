music.

2026

overview

music. is a personal album ranking site hosted at music.amp.ooo. i came up with the original idea was as a new years resulution at the start of the year. i wanted to listen to 3 albums a week, every week. to eventually hit the minimum goal of 156 albums by the end of the year it originally started as an apple notes doc and eventually grew to be too long to manage.

every month i update the website, pulling data from iTunes, Discogs, Spotify, Soundcloud and Album of the Year. working around api rate limits and inconsistent metadata across sources to produce a clean, unified dataset.

stack

  • static html / css / js — no framework
  • google sheets csv as the backend data source
  • spotify oembed for cover art
  • itunes api + aoty scraping for metadata enrichment

features

  • smart search across artist, album, and genre fields
  • genre filter ui with autofill
  • grid and list view toggle
  • mobile expand interactions
  • /10 page — a dedicated view for perfect albums
  • eventual 156-album personal listening log with full metadata

design

built on the amp.ooo design language as — Courier New, four css variables, all lowercase. the palette shifts to a dark purple to distinguish it from the main site while staying within the same system.
